## Fixed-normalization qualification for the source minimum kappa

The source writes c_k in both occurrences of

    kappa = c_k * min(theta, 1/100, (c_k/B)^(1/alpha)).

It also permits fixed normalization constants in the theorem's constants immediately after(5.3). The new original-data statement makes a permissible choice for each such fixed normalization. With normalized width w', the actual fixed two-ends normalization factor C and length dilation W, the choice is

    c* = 1 / [100*(2*w'+1)*C*W].

All of w',C,W are fixed before alpha,B,theta,xi,lambda,N and the family. The same c* occurs both outside and inside the1/alpha power. This is a theorem with the unspecified source constant chosen for the fixed normalization; it does **not** compare its kappa uniformly in alpha to a previously prescribed dimension-only or width-only c_k. Such a comparison would contain(c*/c_old)^(1/alpha) and can fail as alpha tends to zero. If the source subscript is intended to prohibit the fixed-normalization dependence explicitly allowed by the prose, that stronger reading remains a formulation distinction. The report must retain this qualification rather than say two different minima are comparable.

3. **Literal theta-net computation(6.19).** The current actual cap tests are centered at every original tube direction (`SamplingCapTests.cap`), with radius2theta. There are exactlyM angular tests per cell; ambient packing bounds M by a constant times N^(k-1), and the generic failure budget safely uses a polynomial such as N^(2k). The source instead constructs a theta-net of the entire projective sphere, whose size is O(theta^(-(k-1))); theta^(-1) is only a fixed log power, so the source reduces all high-cell/net tests to N^(k+2) and writes the explicit<1/8 display. The existing **same numerical choice** a0=64(k+4) is already sufficient for the formal construction's larger polynomial and its existence result. It is nevertheless false to identify that larger test family with the source net or to claim it automatically satisfies the smaller N^(k+2) cardinality. A literal completion should construct a full projective theta-net with the actual ambient-minus-one packing bound, prove every theta-cap lies in an actual radius2theta net test, integrate the same raw marked means over those tests, absorb the fixed polylog net count into N^2 at a uniform threshold, and expose the source separate<1/8 budgets/combined>3/4 probability. The original sampling existence conclusion, its axes, theta and density/mark guarantees are already covered.

4. **Optional AppendixA bush route.** The actual bush lemma, all scalar maps/domains/margins and both endpoint conclusions are proved. The optional stage-by-stage route starting from the bush exponent, supplying the lifted bush input to the direct marked pivot, applying the all-angle/two-ends reductions, and feeding the resulting diagonal estimate back as the next base is not yet an exposed instantiated induction. Completing the prescribed route would verify the source's claimed alternative derivation, not establish a currently absent maximal bound.
