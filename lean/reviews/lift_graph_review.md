# Independent review: LiftGraph

Reviewed the current LiftGraph.lean after the angular assignment checkpoint. No projective-metric, scale, coloring, constant or quantifier defect was found. No edits were made.

The graph vector is the actual normalization of (1,v), with its distinguished coordinate moved to the first position by an orthogonal coordinate convention. Its norm is at least1, which proves nonvanishing and justifies normalization. The forward bound2||v−w|| is uniform without a slope bound. The ordinary inverse bound2(1+V)^2 correctly uses the head coordinate to control both normalization factors and the tail to recover the slope. The separate projective inverse theorem explicitly handles the closer-antipodal branch: positive graph heads bounded below by1/(1+V) prevent an unnoticed sign degeneracy. The inverse statement is therefore genuinely for min(||u−v||,||u+v||), not just for the ordinary chord.

The fixed-pivot cap-label theorem first compares two graph directions through an arbitrary cap center, which costs radius2r. The inverse chart costs2(1+V)^2, and the two slope residuals cost2Cdelta≤2Cr. This yields exactly the advertised (4(1+V)^2+2C)r label ball. It handles an arbitrary cap center by selecting an existing cap member; the empty cap is treated separately. Label injectivity is explicit and is used when transferring cap population into the actual finite grid-label set E. Without that premise the count could acquire arbitrary label multiplicity, so downstream constructions must retain it.

The cap-count bridge assumes the already-pruned spatial estimate for every radius R≥delta. Its use at R=(4(1+V)^2+2C)r can exceed1, even though the output TubeFamily.CapBound tests r≤1. Thus if a caller has only a spatial estimate for R≤1, it must first extend that estimate over this fixed larger radius range. This is a visible input-domain obligation, not an error in the theorem. The dependence on the fixed V and C is explicit; saying the result is kappa-free additionally requires that the application prove V and C independent of kappa, which the file itself does not silently assume from any other pivot parameter.

Modular coloring uses Q=ceil(2C+1), so 0<Q≤2C+2. Distinct same-color labels differ by at least Q in some integer coordinate, giving actual grid-center distance at least delta*Q. The two residuals consume at most2Cdelta, leaving delta in slope difference. The graph inverse then gives separation delta/[2(1+V)^2]. The theorem keeps the entire color map into Fin k→ZMod Q; it does not incorrectly select one color while claiming to retain every line. The number of possible colors is the finite type's standard Q^k, although the theorem does not separately restate that cardinality identity.

Finally, `lifted_family_cap_bound` constructs the exact existing predicate with coefficient F*(4(1+V)^2+2C)^d. The factorization uses positive real bases and therefore works for real d. No analytic lifted-line estimate, energy inequality, or pruning construction is proved by this graph-chart file; those remain the explicit upstream/downstream interfaces.
