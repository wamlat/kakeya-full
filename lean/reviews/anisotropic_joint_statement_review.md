# Joint anisotropic marked normalization: statement review

Read-only independent review, 6 September 2026. Read `AnisotropicJointShading`, `MeasurableMarkedSelection`, and `AnisotropicJointRecovery`, including the appended `density_parameter`. No edits and no duplicated source/kernel audit.

No substantive defect found. The statements close the previously identified mismatch between independently chosen full/marked unit segments and the old restricted angular union.

`AnisotropicJointShading` chooses `bestSegment` using the actual marked set G. The full shading is the image of the actual input Full intersected with that SAME segment carrier. Consequently marks are subsets of full, each is in its own original image, and the entire full union stays in the common image of the input Full union. If the input Full is the earlier exact restricted Ref, this is the required old-piece boundary. Empty individual marked sets are allowed; the marked-mass lower bound is per-tube multiplicative and requires no positive marked density on each tube. The Jacobian is tau^(-k) in ambient k+1, correctly distinct from grid-support counting.

`MeasurableMarkedSelection.select` first discards tubes with very small actual O mass, then chooses a dyadic class of actual full Y mass using retained O mass. It has no per-tube marked density hypothesis. It constructs a nonempty class with strict factor-two full mass and D+1 <= log(4/eta)/log2+2. The later marked filter uses the multiplicity of ALL original Ref indices, not merely selected reference indices. With L=8(D+1)/eta, the selected-class lower bound implies L*classMarked >= 2*totalRef, so integrating the pointwise discarded inequality genuinely retains half the class marks. Broadness is proved separately with actual O subset Ref, an injective original-index map, and this proportional denominator. The generic selection theorem itself does not claim broadness without that subset/broadness input.

`AnisotropicJointRecovery.construct` instantiates Ref as the common image of the ORIGINAL G and Full' as the common image of Full; Y and O are the paired common-segment restrictions. Its eta'=eta/segmentCount and lam'=lam/tau^k give the correct total marked budget. The constructed class has actual marked/full fraction eta'/(8(D+1)), pointwise marked broadness with the stated transport and proportional factors, and full two ends with coefficient B*(4/eta'). The two-ends assertion concerns full Y restrictions, not marked sets. The same common affine map is used for all tubes in the group. Output union containment and its real-volume upper bound use the same input Full union.

The appended density adapter must be used with the physical input full-mass parameter lamPhysical=lambda*delta^k and eta=eta'. It then gives lambdaNew=density/[2*(delta/tau)^k], with eta'*lambda/4 <= lambdaNew <= lambda <=1 and output full volumes in [2*lambdaNew*(delta/tau)^k,4*lambdaNew*(delta/tau)^k). Thus fixed sampling constants c0=2,C0=4 are justified; they do not hide a scale-dependent comparability factor.

Boundary: these statements do not by themselves construct a normalized spatial box or establish the transformed family base bound, delta/tau separation, or real-cap bound. Those must be supplied from the actual box assignment and anisotropic direction/cap interfaces, with the class inherited through its injective map. Sampling also requires the positive exponent and fixed logarithmic conditioning budgets. These are explicit integration needs, not flaws in the current theorem. The general theorem's `lam` is a mass, not automatically a dimensionless tube-density parameter; `density_parameter` is the precise bridge and should be used rather than relabeling that variable.
